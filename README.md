# 🤖 Aatroxa Bot

A fun and interactive Telegram bot featuring games, coins, daily rewards, and more!

## ✨ Features

- 🚀 `/start` — Start the bot
- ❓ `/help` — Show available commands
- 🎮 `/games` — Open the games menu
- 🎲 `/dice` — Roll the dice
- 🪙 `/coinflip` — Flip a coin
- ✊ `/rps` — Play Rock Paper Scissors
- 🎯 `/guess` — Guess the secret number
- 🎁 `/daily` — Claim your daily coin reward
- 💰 `/balance` — Check your coins
- 🟩 `/grid` — Search the mystery treasure grid
- 🔤 `/wordchain` — Start a word-chain game
- 📝 `/word` — Play the next word in the chain

## 🎮 Games

Aatroxa includes several fun games:

- 🎲 Dice
- 🪙 Coin Flip
- ✊ Rock Paper Scissors
- 🎯 Guessing Game
- 🟩 Mystery Grid
- 🔤 Word Chain

## 💰 Economy

Earn coins by playing games and claiming your daily reward.

Use:

`/balance`

to check your coins.
